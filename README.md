# W1-PEEK

W1 project snapshot containing datasets, annotation outputs, analysis, generation code, and the vendored lloom source.

- `Datasets/`: source datasets, topic subset tables, annotation and interaction-type results, analysis scripts and figures.
- `Generation/`: generation configuration and Python modules.
- `lloom/`: bundled lloom source from https://github.com/michelle123lam/lloom (see its LICENSE and README).

The local Python virtual environment, Python bytecode caches, notebook checkpoints, nested Git metadata, and transient lock files are excluded. All other project files are included.
